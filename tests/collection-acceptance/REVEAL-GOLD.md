# 「揭晓时机与金色文案」验收预备口令

这页只是测试侧的 md。下面的断言都还没写进脚本，产品代码没改，v10a 也没碰。玩家看到的具体文案以小喇叭交的那一页为准，这里只验三件事：结果什么时候能露出来、露出来的内容和收藏实际变化对不对得上、不该出现的字有没有出现。

## 现在骨架能提供什么（v1.1 `model.mjs`）
- `publicResult(state, txId)` 只有在交易 `stage === 'committed'` 时才返回结果，否则抛 `NO_COMMITTED_REVEAL`。骨架自带的测试第 251 行已经验过这一点。
- 返回值里有 `action`，取值是 `collected` / `upgraded-and-dusted` / `dusted` / `gilded`，另外还有 `finish` 和粉尘三个数。
- **缺口**：返回值里**没有**升级之后还剩几张普通。没有这个数，界面没法照实写「仍有 1 张普通」。建议熊大在返回值里加 `after: { normal, golden }`，或者加一个 `remainingNormal`。在补上之前，R2 标「缺接口」，不能算通过。
