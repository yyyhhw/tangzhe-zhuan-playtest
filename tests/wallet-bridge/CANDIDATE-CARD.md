# 钱包桥接候选包验收口令卡

熊大交来候选包以后，按这张卡跑。**只改测试侧，不改产品代码，不碰 v10a。**

## 一条命令
```bash
bash tests/wallet-bridge/accept_candidate.sh <候选包.zip> <帖子里贴的SHA256> [包内实现的相对路径]
```
不写实现路径时，脚本会在包里自动找 `wallet-bridge*.mjs`，`test` 目录下的不算。

## 步骤与期望
| # | 步骤 | 通过的样子 | 不通过怎么办 |
|---|---|---|---|
| 1 | 核对整个 zip 的 SHA256 | `✓ 与贴帖一致` | 退出码 4，直接停下，不解压、不跑。去帖里重取包，或者请熊大重新贴 SHA |
| 2 | 解压后核对包内 `SHA256.txt` | `✓ 包内 SHA256.txt 0 不符` | 有不符的文件：退出码 4，停。包里没有这个清单：只给 ⚠ 警告，不挡后面的步骤，但要记进证据 |
| 3 | 找到实现模块 | 能找到，并且导出了 `createWalletBridge` | `✗ 缺实现`，退出码 1 |
| 4 | 跑 `bridge.test.mjs`，W1 到 W6 共 23 条断言 | `passed 23, failed 0`，退出码 0 | 退出码 1，看 `失败编号：` 那一行，按真失败处理 |

退出码含义：0 = 通过；1 = 缺实现或有真失败；2 = 用法或环境有问题；4 = 包不对。

接口不对齐要先在帖里商量。改接口约定（README）要熊二和熊大都同意。不能为了让候选包通过就改断言，也不能把失败改标成跳过。

## 自测过的情况
- 包对 + 参考桥：23/0，退出码 0。
- SHA 错：退出码 4。
- 包里没有实现：缺实现，退出码 1。
- 参考桥分别注入 7 种错误：每种退出码都是 1。

```
钱包桥接候选包验收
- 包：<文件名> / Slack <file id>
- SHA256：<实际>  与贴帖一致：是/否
- 包内清单：0 不符 / 无清单
- 实现模块：<包内路径>
- bridge.test.mjs：passed <n>, failed <m>，退出码 <rc>
- 失败编号：<W..> 或 无
- 原始输出：附件 <文件名>
- 边界：只证明桥接逻辑本身。G4 真实父页经营扣款、G7 浏览器冒烟、G6 手工验收都不在范围内。walletBridgeApproved 仍由技术复核决定。
```
