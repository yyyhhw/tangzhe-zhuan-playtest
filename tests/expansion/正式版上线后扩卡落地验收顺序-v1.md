# 正式版上线后扩卡落地验收顺序 v1

只写文档，不跑测试，不改产品。

依据 `tests/expansion/扩卡待熊大定稿项汇总-v1.md`（下面写的 A1、B、C1、E11 这类编号都是那份里的），排的是建议顺序：A1 → B 加 C1 → E → 其余。范围是 61 张：签名卡 17（PS/RS/DS/SS）、非签名卡 24（PX/RX/DX/SX）、公共卡 20（N01–N20）。扩卡清单里八个职业那 80 张，等小喇叭的美术 brief 骨架出来再排。

两个说法：
- **可先写用例**：规则口径已经够清楚，现在就能按 `ids.json` 的占位 key 把用例写好；等 id 登记了直接跑。
- **卡定稿**：用例要等熊大定了相关项才能写，或者要靠一个还没做的能力。

## 0 前置：正式版先上线（扩卡不碰正式线）

1. FC7 正式上线，并且拿到上线证据：合并 SHA、部署记录、线上 `/version.json`、140 个文件的哈希比对。
2. 按 `tests/formal-smoke/FC7线上冒烟提纲.md` 跑完线上冒烟，结论交熊大。
3. 扩卡开发和验收都在 preview 和本地候选包上做，正式存档键和钱包不碰。要进正式版，另走候选包、独立复核、冻结发布的流程。
4. 新四职业先要注册：职业、英雄技能、默认卡组。现在扩卡骨架判「未注册」，所以四职业的卡在这一步之前都判 FAIL 未实现。

## 1 第一批：可先写用例，不等定稿（18 张）

规则只用到冲锋、嘲讽、圣盾、潜行、连击、过载、武器这些现有关键词，或者四职业骨架里已经写好的机制（R6–R13、S8–S13），不用等 B、C、E。

| 组 | 卡 | 用例要点 | 备注 |
|---|---|---|---|
| 公共·关键词 | N01、N02、N05、N10、N14、N17、N19、N20 | 数值，加关键词组合：嘲讽+圣盾、冲锋+圣盾；0 攻的卡不能攻击；潜行同 R10–R12 | 冲锋、嘲讽、圣盾王大妈实玩确认过 |
| 潜行者 | RS1、RS5、RX2、RX3、RX4 | 范克里夫按出牌张数加成（0/1/3 张）；剑刃乱舞要有武器；连击伤害和 buff 的目标；5/1 潜行 | RS1 是传说，要不要保留看 A2；RX4 能不能选自己看 C6，那条子用例先挂 PENDING |
| 萨满 | SS2、SX2、SX3 | 回合结束抽牌只在己方回合；过载 3 和过载 2；过载叠加以后下回合法力最少到 0 | SS2 手牌满时抽牌看 B2，那条子用例先挂 PENDING |
| 牧师 | PX4、PX6 | 恢复 5 点，不超过上限；消灭攻击力 ≥5 的随从，验 4、5、6 三个边界 | PX4 满血目标看 C4，那条子用例先挂 PENDING |

- 通用 G1–G9（注册、数值、原创名、牌面关键词、稀有度和收藏、卡图 1122×1402、缩略图、禁忌、重放）对 61 张卡都可以先写成表驱动用例，按 `ids.json` 循环。
- 先写好的用例在 id 登记之前全部判「FAIL 未实现：卡 id 未登记」，不跳过。

## 2 第二批：A1 卡表定稿以后

A1 定了（id、数值、稀有度写进 `ids.json`），连同 A2–A6：

1. 第一批 18 张直接跑；61 张卡的 G1–G9 全部跑一遍。
2. A3 有冲突：「狐人老千」和「耐心的刺客」只能留一张（熊二 05:41 转的小喇叭意见）。定了以后，删掉的那张从清单里移出，不再挂 FAIL。
3. A4 非经典的 6+1 张、A5 公共卡 20 张：不保留的移出清单；保留的数值以设计稿为准。
4. 卡图：按 `ART_BY_SOURCE_ID` 逐张核文件、尺寸，人工看禁忌（G8 要熊大签字）。

## 3 第三批：B 组和抉择顺序（C1）定了以后（5 张，另外解开 22 张卡的边界子用例）

只靠 B、C 就能写全的卡：

| DS2 知识古树、DX3 暴烈枭兽、DX5 野性之怒 | C1 抉择先选选项还是先选目标、取消后怎么回退 |

- 扩卡清单里德鲁伊那 7 张抉择卡的目标用例，也在这一批解开。

## 5 第五批：其余 C、D、F 组和浏览器回归

1. 剩下的 C、D 组（C5、C6、D1、D4、D5、D6）边做边定，定一条就把对应的 PENDING 子用例改成能判过或不过。
2. F 组美术表现（变形形态、衍生物、突袭牌面、治疗变伤害的按钮、临时召唤物标记、过载水晶、公共卡配色）定了以后，才跑卡图和 UI 验收。
3. 浏览器回归：两个引擎（Chromium、WebKit），两种尺寸（844×390、667×375）。满手 10 张、抉择面板、连击高亮、过载水晶、换控制权、变形、回手以后 DOM 里没有残留的旧节点。CSP、`pageerror`、HTTP 错误、资源取消分开记。
4. 要进正式版的话，打成候选包，按 FC 系列的流程走：核包 SHA、manifest 逐个核对、两个引擎验收、独立复核、冻结发布、线上冒烟。
