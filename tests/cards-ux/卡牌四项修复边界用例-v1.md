## 通用前置（每组都跑）
- Chromium + WebKit；844×390、667×375；reduced motion reduce / no-preference；鼠标 + 触摸。
- 合成局面用快照导入或测试钩子，**操作必须真实点击/拖拽**；记录点击坐标、命中节点、UID、revision。
- 非法操作 revision 不变；合法操作 revision +1 且只 +1。
- 审计：CSP、pageerror、HTTP≥400、资源取消，主页面与 iframe 分开。

## T 目标红/绿轮廓
颜色约定（杨总原话）：敌方可影响目标 = 红；我方受影响目标 = 绿。轮廓集合必须**等于**核心 `actions()` 的合法目标集合，不多不少。
| ID | 局面 | 预期 |
|---|---|---|
| T1 | 选中可攻击的我方随从，敌方无嘲讽 | 敌方随从 + 敌方英雄全部红色 |
| T2 | 敌方有嘲讽 | 只有嘲讽随从红；敌方英雄与非嘲讽不红 |
| T3 | 刚上场无冲锋 / 已攻击 / 0 攻 | 不能选中，无轮廓 |
| T4 | 冲锋随从刚上场 | 可选；规则同 T1/T2 |
| T5 | 英雄装备武器可攻击 | 选英雄后同 T1/T2 |
| T6 | 单体伤害法术 / 法师技能（目标 any） | 敌方目标红；我方可选目标颜色见待定 Q2 |
| T7 | 单体治疗（温杯小憩 6、热毛巾摊主战吼 2） | 我方目标绿；敌方可选目标颜色见待定 Q2 |
| T8 | 珍珠护套（圣盾，目标随从） | 我方随从绿，敌方随从按 Q2 |
| T9 | 书架震页 / 闭馆热浪（enemyMinions） | 点牌后敌方随从全部红，敌方英雄不红，我方无标记 |
| T10 | 满场送茶（enemyCharacters） | 敌方随从 + 敌方英雄红 |
| T11 | 后厨大扫场（allMinions） | 敌方随从红；我方随从标记见 Q1；双方英雄都不标 |
| T12 | 整店熏墨（allCharacters） | 敌方随从 + 英雄红；我方随从 + 我方英雄标记见 Q1 |
| T13 | 夜市递汤人（友方全体治疗） | 我方随从 + 我方英雄绿；满血角色是否标记见 Q3 |
| T14 | 随机伤害（random_damage_once） | 可能命中的敌方角色红（标「可能」），不提前暴露结果 |
| T15 | 敌方场上 0 随从 | 群攻只标英雄或不标；法术能否出按核心，不能出时不进入选择 |
| T16 | 取消选择、出牌完成、回合结束、暂停 | 所有轮廓立即清除 |
| T17 | 死亡动画中的复制节点 | 无轮廓、不可点（无 `data-entity`） |
| T18 | 7 个随从 + 10 张手牌 + 展开手牌 | 轮廓不被手牌遮挡；667×375 可辨 |
| T19 | 敌方回合 | 我方无任何轮廓；AI 目标不显示红绿 |
| T20 | 色弱 | 红/绿以外另有形状或图标区分 |

## V 看牌不暂停、设置才暂停
| ID | 局面 | 预期 |
|---|---|---|
| V1 | 我方回合打开牌面详情 / 最近出牌 | 不暂停；状态不显示「已暂停」 |
| V2 | 敌方回合打开牌面详情 / 最近出牌 | 不暂停；AI 继续行动；详情内容随局面刷新或标明「已变化」 |
| V3 | 「暂停」按钮 | 移除（无回合计时，不提供暂停选项） |
| V4 | 打开设置 | 暂停；AI 停止；BGM 按暂停处理 |
| V5 | 关闭设置（关闭键 / Esc / 点空白） | 自动继续，不需要点「继续」；AI 继续 |
| V6 | 设置里改了内容后关闭 | 保存后继续；保存失败则保持暂停并显示失败 |
| V7 | 菜单（牌册/快照入口所在） | 是否算「设置」见 Q5 |
| V8 | 页面隐藏、离开、竖屏、保存失败、规则异常 | 安全暂停是否保留见 Q6；不得被关闭设置自动解除 |
| V9 | 设置打开时页面隐藏再回来 | 关闭设置后才继续 |
| V10 | 快速开关设置 10 次 | 只有一个 AI 定时器，revision 不跳，BGM `created=1` |
