# FC7 线上冒烟提纲

只写提纲，不跑线上。等熊大给出上线证据后再执行。

- 只读冒烟，用全新浏览器上下文和合成档。
- 不用真实账号、真实余额、真实钱包。
- 不改产品，不代推。
- 线上结果只能证明它实测过的那些项。

## 0 前置（缺任何一项都不开跑）

| ID | 项 | 判定 |
|---|---|---|
| P1 | 上线证据 | 熊大给出：合并提交 SHA、部署成功记录、线上 URL |
| P2 | 版本 | 线上 `/version.json` 是 `formal-cards-candidate-7`，或熊大另定的正式版本号，并且和 P1 的提交对得上 |
| P3 | 文件 | 逐个比对 FC7 manifest 140 个文件的线上 SHA256，不一致的列出来 |
| P4 | 环境 | Chromium 和 WebKit（26.6，Playwright 1.63.0），尺寸 844×390 和 667×375，`reducedMotion` 开、关各一次 |

## 1 入口

| ID | 步骤 | 期望 |
|---|---|---|
| E1 | 打开正式入口 `/`，不带 QA 参数 | 首屏出现迁移和欢迎弹窗 |
| E2 | 依次点真实按钮：「同意并继续」→ `#mOk` → 书店 `[data-shop="2"]` → `[data-act=cards]` | 卡牌 iframe 加载正式版本，`getDiagnostics().ported===true` |
| E3 | 卡牌菜单 → 牌册 → 各标签页 | 抽卡、牌册、卡组、设置都能打开；只读冒烟不确认交易 |
| E4 | 打开 preview 入口 `/preview/` | 和正式版分开：正式页只写 `tangzhe-formal-*` 键，preview 页只写 `tangzhe-preview-*` 键 |
| E5 | 资源引用链 | bootstrap、`app.js`、卡牌 `app.mjs`、`bgm.mjs` 都带 FC7 版本参数，没有请求旧版本 |

## 2 四个模式的 BGM（经营、打僵尸、塔防、卡牌）

| ID | 步骤 | 期望 |
|---|---|---|
| B1 | 首次点击后 | 经营 BGM 开始播放，点击前不出声 |
| B2 | 依次进入打僵尸、塔防、卡牌 | 任何时刻只有一个模式在放音乐；进子模式时经营页的 AudioContext 挂起 |
| B3 | 退出各个子模式 | 子模式的 iframe 卸载后，经营 BGM 才恢复 |
| B4 | 在任一模式里静音，然后刷新 | 四个模式共用同一个静音状态，刷新后仍是静音；子模式里的点击不会把声音打开 |
| B5 | 暂停，或切到后台再切回 | 暂停期间不出声；恢复后只有一个音源（`created=1`） |

## 3 手牌关键词

| ID | 步骤 | 期望 |
|---|---|---|
| H1 | 手牌数 1 到 10 张，两种尺寸，展开手牌 | 冲锋、嘲讽、圣盾等关键词直接写在牌面上；英雄技能写明费用和效果 |

## 4 存档迁移和回滚（只用合成档）

| ID | 步骤 | 期望 |
|---|---|---|
| S1 | 灌入老玩家的合成档，选「暂不进入」 | 不写入任何正式键 |
| S2 | 选「同意并继续」 | 迁移到 `tangzhe-formal-collection-v1-save`，字段保留 |
| S3 | 坏档、未来版本、只有备份三种合成档 | 页面显示「正式存档已保护」，源档原字节不变，不建零档 |
| S4 | 回滚演练（由熊大按回滚方案执行，冒烟只核结果） | 卡牌入口隐藏，经营档保留，正式键不被删除 |
| S5 | 刷新 | 余额和收藏不变；有没收好的揭晓结果时只再展示一次，不重复扣费 |

## 5 音频接缝，以及进出卡牌时的静音

| ID | 步骤 | 期望 |
|---|---|---|
| A1 | 线上 WebKit 卡牌页读 `getDiagnostics().bgm` | `decodedFrames`、`loopFrames` 和本机 FC7 结果一致（WebKit 是 2,200,576 / 2,196,166）；`loopStart=0`；`loopEnd` 等于 buffer 时长 |
| A2 | 对线上的 m4a 运行 `fc2-audio-browser` 中的接缝测量（只读，`TEST_BASE_URL` 指向线上） | 接缝和两圈渲染的跳变都小于 0.08，阈值不改 |
| A3 | m4a 的线上 SHA256 | 和包里那份一致；对比 CDN 返回的 `Content-Type` 和缓存头，把实际值记下来 |
| A4 | 进卡牌 → 静音 → 退出 → 再进 | 静音状态保持；退出后经营 BGM 恢复，两边没有同时出声 |
| A5 | 音频临时下载失败（只能用本机拦截线上请求来模拟） | 能重试恢复；只建一个音源 |

## 6 审计（每一项都分主页面和 iframe 记）

- CSP
- `pageerror`
- console error
- HTTP 4xx/5xx
- 资源取消（关 iframe 时取消的卡图、宠物图）

另外：
- 截图会带出 CSP 报错，所以审计用不截图的那次运行，截图另跑一次。
- WebKit 下宠物 manifest 报 access control checks、但 HTTP 是 200 的那几条，单独列出来。

## 7 不在本次冒烟范围，也不能声称已验证

- 真机 iOS Safari
- 真实切到后台后进程被系统杀掉
- 线上真实扣费的端到端（需要钱包开关，冒烟不碰）
- 有人实际听过 BGM 接缝（证据里 `listeningReviewed=false`）
- CDN 在多个地区的缓存表现
