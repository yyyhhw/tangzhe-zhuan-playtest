## 方法
- **前脚**：缩略图 alpha>8，在最底部找两组腿部不透明像素（左/右两条腿），取每组最低一行作为接地行。三款底部的两条腿是同一行，都是前端的两条腿。
- **后脚**：三款都看不到后腿，被车身挡住了 → **无法直接测定**。`annot/` 里的红点是参考推算，不是实测：
  后脚 y = 后端参照线 + (前脚接地 − 前端参照线)。参照取前后同一高度的结构（普通款：扶手前/后棱；贝壳款：涡卷扶手；管道款：横管蓝色皮套上沿），**没有**拿靠背顶或管道顶端当落地点。
  贝壳款参照线不确定，误差约 ±30 缩略图像素（约 ±0.1 格）。
- **房间**：WebKit 模拟 iPhone SE（格宽 47px）和 iPhone 15（格宽 59.2px）；三款在 x=0/2/4、y=1 分别摆 rot1 和 rot3（占地 1×3）。横向对照摆在 (0,0)、(3,0)，合法、不越界。
  用图片的实际显示框换算前脚、后脚在屏幕上的位置，再和占地前沿、后沿比较。`*_feet.png`：绿点 = 前脚，红点 = 推算后脚，蓝虚线 = 占地前沿/后沿。
