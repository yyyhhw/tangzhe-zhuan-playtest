- 每家店 1 位 CEO + 1 位员工；店铺、员工、CEO 三样分开升级；里程碑 Lv10/25/50 → ×2/×4/×8

- 16 件不重复盲盒（熊大卡池），科技公司雇到员工后开放，单价 20 万（可调），只花游戏金币、不加产速
