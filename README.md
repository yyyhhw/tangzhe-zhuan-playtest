# 躺着也能赚（试玩版 v1）

iPhone 竖屏 Safari 漫画风挂机小游戏。**试玩链接，不是正式上线版**（杨总点头后再上线）。

- 四家店：77烧烤摊（免费）/ 奶茶店（1,000）/ 漫画书店（6 万）/ 摸鱼科技公司（400 万）
- 每家店 1 位 CEO + 1 位员工；店铺、员工、CEO 三样分开升级；里程碑 Lv10/25/50 → ×2/×4/×8
- CEO：77、珍珠姐、阿宅店长、火箭老板（名字在 `economy.js` 的 `ROCKET_NAME` 一处配置）；专长 ×1.5 / 跨行 ×1.2，4 个跨行事件；调任前预览每家店和全街收益变化（目标店有人 →「交换任职」，显示两家店 $/s 变化；先按旧阵容结清收益再换人，店铺进度不动）
- 文案：熊大定稿——16 块招牌（CEO×店，火箭老板一行 老马烧烤／特嘶啦奶茶／漫威书店／火箭科技 跟随 `ROCKET_NAME`）、员工 阿炭／小满／阿页／小栈、4 个两格跨行漫画
- 离线 50%、最多 8 小时（「麻辣服务器」+2 小时）；大客户 ×5 只算在线；每日双倍马来西亚时间早上 5 点重置，先封顶再翻倍
- 盲盒 v2：36 件不重复（普通收藏 32 件：衣服/帽子/装饰/故事卡各 8 + 超级装饰 4 件），科技公司雇到员工后开放，固定 20 万一个；超级装饰 10%、15 抽保底；只花游戏金币
- 超级装饰（每店一件，只能抽到）：熊猫食神 / 珍珠喷泉 / 次元传送门 / 人造太阳反应堆，本店产量 +30% + 专属效果；暴击概率和暴击倍率分开显示
- 衣服帽子穿在 CEO 身上，每位 CEO 各穿各的，换店跟着人走
- 存档带版本号（v2，自动迁移旧档）；领钱/开盒原子保存；同一时间只能一个标签页玩；切后台声音暂停

开发：`node test_economy.js`（经济单元测试）、`node sim.js [盲盒价] [涨价倍数]`（节奏模拟器）、`python test_playtest.py URL`（WebKit/iPhone 端到端测试）。
