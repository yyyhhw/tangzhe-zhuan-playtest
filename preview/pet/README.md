# 宠物原型 p3 / p4 / p4a / p4b（preview/pet/）

> **p4**：小狗接进完整游戏流程 → `game/`（预览快照副本 + 小狗）。见下方「p4」。p4 / p4a / p4b 需单独验收后才并主线。

独立页面：一只暖棕白小狗在房间里自己过日子。和正式游戏完全隔离：
- 只用自己的存档键 `tangzhe-pet-proto`；不读不写 `tangzhe-save` / `tangzhe-preview-save`；不接经济，收益加成 0。
- 家具目录只读 `../economy.js` 的 `FURNITURE`（200 件，占地 w×h 照用），真图用 `../art/furn_*.webp`。

## 文件
- `engine.js` 行为引擎（纯逻辑）：网格 A*（0.25 格分辨率）+ 精确线段拉直；碰撞 = 脚下圆（半径 0.22）+ 按朝向的身体盒（p3）；需求 / 状态机；球的物理；搬家具；存档 / 离线。
- `room.js` 测试房间摆设 + 「鼻尖位置 / 朝向 / 动作」互动配置（只有配了的家具才有专门互动：自己的窝、碗、3 个猫窝 / 猫吊床）。
- `art.js` 美术 manifest 校验 + 动画播放器；`art/manifest.json` 占位 manifest；`art/MANIFEST.md` 合同说明。
- `puppy.js` 占位小狗（程序绘制，按 manifest 原点和嘴巴锚点画）。
- `main.js` 页面：画布渲染、三个操作、搬家具、存档、测试钩子（`__pet`、`advanceTime`、`render_game_to_text`）。

## p2 修复（熊大 p1 复核）
- 叼着球被摸：先安全放球（在你面前就算送回）再被摸；任何计划被打断后嘴里还叼着球，下一个自主计划先原地放下，不会一直叼着、不用呼唤也能再抛。
- 读档精力只认有限数值，合法的 0 保留为 0（以前 `数值 || 70` 把 0 当缺失），再单独加离线休息；0 精力读档后是累的、会去休息。

## p3 修复（熊大 p2 复核）
- (a) 互动目标绑定家具 uid（同款两件也不认错）。布局一变（obsVer 变）就重算这件家具的互动站位：还在走 → 改道去新站位；已经在闻 / 守着 → 跟到新位置重新闻，旧位置不再闻；家具没了 / 新站位站不下 / 走不到 → 取消计划（愣一下换别的事）。
- (b) 读档先把存档里的整组布局放上，再统一查冲突：单件出界 / 压窝压碗回默认；两两重叠时每轮挑冲突最多的「不在默认位」的件回默认（平手优先回「默认位空着」的那件，再按 uid）。合法交换 / 三件轮换都保留，结果与存档记录顺序无关。
- (c) 碰撞按小狗实际外形：manifest 新增 `body`（E/N/S 每个朝向所有帧的左右像素范围，含鼻尖 / 尾巴尖 / 耳朵，逐帧量出），引擎换算成按朝向的身体盒（东：前 0.63 / 后 0.58 格；南北：左右约 0.28 格；纵深 ±0.22）。规划、走路、转身、东张西望、原地动作、叼球站位、搬家具（不能压到鼻子 / 尾巴）都按身体盒查；走动朝向按「这一段」定，和规划用同一条规则。互动站位按鼻尖反推，鼻尖贴边不进图。

## p4a 修复（熊大 p3 复核：1 格宽竖走廊转不开身仍播侧身动作）
- 原地动作（抚摸 / 张望 / 闻 / 蹦 / 拨球 / 吃 / 趴下 / 睡 / 起身 / 叼放球）只画侧面，开播前统一过「侧身守卫」（engine `sideGuard`）：当前侧面身体盒放得下 → 播；另一侧放得下 → 换那侧播；两侧都放不下 → 自主类动作（闻 / 蹦 / 吃 / 趴下睡）先按路程找整间屋最近、走得到的能转身处（网格 Dijkstra），挪过去再播；还不行（死胡同 / 被围住）→ 保持原朝向（南北站姿）用替代：抚摸 = 站着摇尾巴（照样冒爱心、加亲密），放球 = 直接放下，睡觉 = 站着打盹（照样回精力），其余取消。抚摸 / 呼唤 / 抛球 / 自主行为全走这一处（游戏 `game/` 共用同一个 engine.js，一起修好）。
- 顺修：窝走不到（死胡同里）就原地休息，不再反复「走回窝 → 走不到 → 愣一下」。
- 回归：引擎 section 20（1 格竖走廊 / 横走廊 / 死胡同 / 边界格：点小狗、按钮摸、呼唤、抛球、困了、自主 2–3 分钟，逐帧独立身体盒），原型 e2e + 游戏 e2e 各加 4 个场景（真点屏幕上的小狗；原型同时查屏幕像素）。旧代码（12e1b29）上：引擎 14 挂、原型 e2e 27 挂、游戏 e2e 30 挂。

## p4b 修复（熊大 14:14 满屋崩溃 / 14:17 坏档 NaN）
- **满屋 = 正常状态**：屋里没有小狗能站的地方（脚下圆 + 竖身体盒都放不下，例如 6×4 小屋合法摆满 24 个花盆）时，引擎不再崩（以前 `nearestFreePoint` 返回空、`createWorld` 读 `bp.x` 报错），而是进 `w.noRoom`「等待安置」：不画小狗 / 窝 / 球、不动、三个操作回 `noRoom`；布局一变（`setLayout` / obsVer）就重找安全站位（`safeSpot`：附近 → 整屋网格，绝不退回到压家具的点），找到就从门口那边出来。
  - 没买：购买前先查（`PetGame.hasRoom`，和真正入宅同一个建世界流程，按布局缓存），没位置商城卡显示「暂时无法入宅」（禁用），硬点 / 直接调 `buy` 也拒绝，**不扣钱、不写 pet**。
  - 已经有了：读档时满屋、布置把最后的空地挡满、搬进满屋、升级房子前后——所有权不动，家宅显示「小狗等待安置：…收起或挪开一件家具、或升级房子」，腾出空地自动出来（有提示），精力 / 亲密照常保留，存档照常写。
- **坏档逐字段容错**：`engine.sanitizeSave` 逐字段校验 pet.eng（savedAt / t / rs / 坐标 / 朝向 / 精力 / 亲密 / 冷却时间戳 / 球）：只认有限数值 + 范围，缺失 / 非法给默认，**合法的 0 保留**（精力 0、t 0、savedAt 0、lastGain 0、boughtAt 0）；亲密夹到 [40, 99999]、精力 [0, 100]、冷却时间戳不晚于 t、savedAt 缺失或在未来 = 离线 0 秒、坐标非法 / 出屋按房间重找安全站位、朝向只认 E/W/N/S（不认原型链上的 "toString"）。`serialize` 只写有限数值。`PetGame.norm`：pet 是对象就算买过——owned / home / boughtAt / eng 哪个坏了修哪个，**不再清掉所有权**（只有 pet 不是对象或明确 `owned:false` 才当没买）。
- 回归：引擎 section 21、游戏接入 section 10 / 11（三档合法满屋购买、已有宠物满屋读档、布置挡满、搬进满屋、升级房子，逐项核金币和宠物数；pet.eng 16 字段 × 11 种坏值 = 176 例 + 外层字段 14 例 + 合法 0 / 范围 / 48 小时离线），原型 e2e + 游戏 e2e 各加满屋 / 坏档场景。旧代码（f9d166c）上：引擎 7 挂、游戏接入 48 挂、原型 e2e 15 挂、游戏 e2e 56 挂。
- `game/` 用 `mkgame.py` 基于预览 12c1 重新生成。

## p4：接进完整游戏（`game/`）
入口：`preview/pet/game/?v=p4b`（p4b 起）。流程：商城（家宅 → 商城，第一张卡）买小狗 3000 金币 → 住进当前 CEO 的家宅 → 自己逛 / 闻猫窝 / 回窝睡 / 玩球，生活模式下呼唤 / 摸摸 / 抛球、点小狗 = 摸摸 → 刷新存档保留（短离开原地接着来，离开 ≥20 秒算在窝里睡了一觉，回精力不扣亲密）。
- **文件**：`game/index.html`、`app.js`、`economy.js`、`style.css` 是预览（当前 12c1）的快照副本，`art/` 路径改成 `../../art/`，版本号 p4；改动只有小狗钩子（app.js 里搜「宠物 p4」）。`petgame.js` = 小狗接入层（存档字段 / 购买 / 家宅布局同步 / 画），`petgame.css` = 样式。生成脚本 `tools/game/mkgame.py`（钩子代码在 `tools/game/glue.js`，主线更新后重跑即可）：只替换资源路径、版本号、插入钩子，不动经济 / 存档 / 家具逻辑。
- **存档**：沿用游戏原来的键（`tangzhe-preview-save` / `-bak` / `-tab-lock`），**不新增、不改名任何键**；小狗只占存档里一个字段 `state.pet = { v:1, owned:true, home, boughtAt, eng }`（eng = 引擎存档：位置 / 精力 / 亲密 / 球，不含家具）。没有 `pet` 字段 = 没买，旧档照常读、读完也不多字段；pet 不是对象 / 明确 `owned:false` 才当没买，其余坏字段逐个修（p4b）；家没开放就搬回第一个开放的家。`E.migrate` 本来就保留未知字段，所以主线预览读写这份档也不会丢小狗（e2e 验过）。根目录 `app.js` 不动。
- **家具**：一律以家宅摆设为准，每帧比对，变了就 `engine.setLayout` 整组换上（uid 沿用，互动目标按 uid 跟）；升级房子尺寸一起换。家宅的摆放规则不认识小狗：家具摆到它脚下，它会挪到最近空地。布置模式下小狗停下等（`setRearrange`），按钮收起。
- **小窝**：不占家具格，自动找空地（优先左前角，平的能踩），被家具压住就换地方；窝放不下时画在左前角、小狗原地趴着睡；连小狗都站不下 = 等待安置（p4b）。家宅里没有饭碗（`room.bowl = null`）。
- **画**：小狗 / 窝 / 球是 `#roomFloor` 里的绝对定位元素；地上家具按占地前沿写 `--fz`，小狗按落地点排，前后遮挡一致；CEO 小人在最上层。
- **换正式美术**：和原型共用 `art/manifest.json`。熊大的图集到了 = 图集放 `preview/pet/art/`，manifest 改 `placeholder:false`、`atlas.image` 指向文件名，帧序 / 锚点 / `body` 按真图改，代码不用动（e2e 用烘出来的图集模拟过这条路）。
