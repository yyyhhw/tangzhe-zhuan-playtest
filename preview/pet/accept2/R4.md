# 双宠 r4 测试分支说明（基于 r3 26e09cd + 13k/p7a，基线 13j 932ba25）

只是测试候选：不合 main、不上线。版本号沿用 13k / p7a（13k 尚未发预览）。

## r4 行为
1. 购买：钱包异常 / 存档不可写（saveBlocked、frozen）/ 余额不足 / 目标房间没空地 → 确认键禁用，`#pbWhy` 写明原因；提交时 `petBuyWhy` 再查一次；`PG.buy` 自身也拒绝。失败不改金币、名单、成长。
2. 两只名额（`needReplace`）和地面空间（`PG.hasRoom` / `noRoom`）分开：名额满 → 替换或买入待命；地面满 → 不给替换 / 入住，只给「购买后待命」；明确待命不受地面限制，不改目的地。`PG.assign(..., {M})` 搬家也做地面检查。
3. 购买入住 / 搬家成功 → 切到目标房间；失败、买入待命、回待命不切房。
4. 等待安置：`[data-pet-wait]` 提示、呼唤 / 摸摸 / 抛球禁用、保留「回待命」；有空地后恢复并提示「跑出来」。布置模式显示 `#petNote`。
5. 存档里未开放 / 未知房间 → 待命，uid / 种类 / 成长原样。
6. `PG.engSupport(p)`：`empty` / `ok` / `unsupported` / `opaque`（非狗）。只有空成长初始化新狗；不支持的狗引擎版本（顶层或 dog/ball 内带 `v`、或非对象）原样保留、暂停模拟、不写回，界面提示「成长存档版本不支持」；猫的嵌套版本不被解释或改写。
