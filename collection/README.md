# 正式收藏接入 FC7

以正式经营应用和经济模型为底增量接入，预览存档不导入。正式根页与独立宠物页共享同一存档协调器和生命周期 Web Lock；旧正式标签继续写旧键，无法覆盖新进度。

首次迁移须确认。旧主档、备份、v15 升级快照原文保存为不可变摘要归档，摘要绑定新版主档；每次启动和提交均验证。确认期间来源变化需重确认。取消不写入；损坏、未来、仅备份、迁移残留、缺失字段档进入保护状态。不得清空后静默创建零档。

新版主键：`tangzhe-formal-collection-v1-save`。所有经营保存使用 `host-save.mjs`；收藏必须通过 `host-wallet.mjs`。PREPARED 固定结果，COMMITTED 同主档原子扣金币/发卡，永久请求去重。写入或回读不确定时只读，刷新后核对实际原文，不盲目回滚。

规则配置：粉尘上限 50000；单抽 5000000 金币；稀有度 68/22/7/3%，档内均匀；条件金色概率 5/5/5/10%；普通合成费用 40/100/400/1600；普通重复补偿 5/20/100/400，全金满额时金色重复补偿 20/80/400/1600。无保底、无镀金、不能合成金卡。满额含普通而抽金：换一张普通并给普通重复粉尘。未满额保留实际抽出的外观。溢出在确认前提示，取消不抽样、不扣费、不保存提醒偏好。

旧规则完成态可显式升级，保留普通/金卡、粉尘、回执及经营字段。旧规则未完成交易保留原文只读等待人工复核；FC1 无摘要绑定的原档不能自动认定可信，亦需复核。历史镀金回执仅用于验证旧历史，并非新功能。

回滚采用关闭 `release-gate.mjs` 的入口和交易开关，保留新版经营存档协议。不可整站回退后读取旧进度。新版暂不支持清空重开，避免删除永久交易回执。

测试：`node --test tests/formal/*.test.mjs`、`node tests/formal/protocol.mjs`、`node --test cards/tests/save.test.mjs`。浏览器测试设置 `PLAYWRIGHT_MODULE`（Playwright 入口）、`PLAYWRIGHT_BROWSERS_PATH`，可选 `TEST_ENGINE=webkit`，在仓库根启动 HTTP 8788。旧标签和缓存测试需把固定基线导出至 `/tmp/formal-baseline`。测试截图/日志属于内部复核产物，不加入产品提交。

## FC5：正式塔防升级回执

顶层可选 `tdUpgradeReceipts` 保存版本 1、正式范围与当前塔防规则集下的永久升级请求回执，与金币和等级同次提交。缺少该字段的旧档继续兼容，首次成功升级才建立，不猜补历史请求；存在但损坏、null 或未来版本则保护原档。回执只追加，不可普通保存删除或改写。相同请求返回原升级结果，异塔或异规则集拒绝；新请求编号正常购买。正式根页及独立宠物页共用校验和唯一写档协调器，回读不确定通过协调器确认落盘后再重试。

缓存链提升至 `formal-cards-candidate-7`，包含独立加载的 TDHost、新回执校验模块和塔防 iframe 脚本。不变更正式主档键、v15迁移、金币零头、塔防结算逻辑、BGM或卡牌经济参数。FC4及之前没有回执的历史升级无法恢复其原 requestId；不会生成伪历史回执。

## FC6：iframe 退出兼容处理

FC4、FC5 均可在 WebKit 退出卡牌时触发原生 CSS/无障碍缓存崩溃，日志为 `AXObjectCache::performDeferredCacheUpdate → computedStyle → CSSCalc → RenderView::zoomFactor`。FC6 在唯一父页关闭路径中、导航到 about:blank 之前，同步停用即将销毁文档的样式表并完成布局，避免延迟样式查询依赖已销毁的 RenderView。仅处理即将退出的 iframe；正常/强制关闭共用该路径，重新进入加载全新样式。没有等待计时器，没有省略父页音频恢复，没有改 BGM、存档或卡牌规则。原完整回归断言保留；五次串行 WebKit 通过，冻结旧路径反向对照仍崩溃。

小型 HTML/CSS 复现页尚未触发，不能断言某条 CSS 表达式独立致错；现有依据为真实页面原生崩溃栈、跨端口/缓存标记对照及兼容处理 A/B。

## FC7：按实际解码 PCM 构建 BGM 循环

删除固定 loopEnd 帧数。成功解码后由 `prepareCardBgmLoop` 一次性生成约100ms首尾交叉淡化PCM并缓存；实际播放源显式loopStart=0、loopEnd=处理后buffer.duration。首尾跨圈为原PCM相邻采样，混合段入口保留原尾部相邻采样；不根据UA猜padding，不设置人为零端点。暂停、静音、恢复不重复处理。AAC素材及下载体积不变。短buffer缩短重叠，少于4帧安全拒绝，不生成空/非法buffer。

音频单元及Chromium/WebKit实际PCM、Offline两圈渲染、真实AudioBufferSource边界、网络/解码失败重试、异步resume、关闭生命周期回归通过。阈值仍为0.08，并增测混合段入口与渲染跨圈跳变。复核机出现的2,200,576帧WebKit解码在本机版本未复现，合成padding压力另行标注，不冒充该环境实测；仍需独立复核机用同包重跑。
